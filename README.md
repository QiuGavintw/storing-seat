# 教室座位編排工具（storing-seat）

一個純前端、單頁式的「一般教室座位編排」網頁工具，適合單班級／單教室情境。可在瀏覽器中設定教室佈局、匯入學生名單、依規則自動抽號排座，並支援手動微調與多種匯出方式。資料預設儲存於本機瀏覽器（`localStorage`），無需後端與資料庫。

- 線上版本（GitHub Pages，若已啟用）：https://qiugavintw.github.io/storing-seat/
- 儲存庫：https://github.com/QiuGavintw/storing-seat

## 功能特色

- **教室佈局**：自訂行列數、顯示黑板與教師桌（左/中/右）、設定講台與空區/禁用格、鎖定座位
- **名單管理**：貼上 CSV、上傳 CSV/Excel、手動新增與編輯；提供範例 CSV/Excel 下載
- **排位規則**：隨機／依學號／依姓名排序、多種填入方向、前後排需求、男女盡量間隔、分組分散、限制標記分開、固定座位
- **互動調整**：拖曳交換、右鍵選單（鎖定/禁用/指派等）、復原/重做、編排歷史版本
- **檢視與輸出**：座位圖字級調整、放大座位圖、全螢幕檢視；匯出/匯入 JSON、匯出名單 CSV、匯出 PNG、列印/存 PDF
- **介面**：繁體中文（zh-TW）、深色模式、RWD（桌機優先並支援平板/手機）、本機自動儲存

## 使用方法

### 1. 設定教室佈局
- 於「教室佈局」設定**行數／列數**、是否顯示黑板與教師桌、教師桌位置。
- 在座位圖上**點選格子**可切換格子類型（一般座位／講台／空區禁用）。
- 編排時會保留已鎖定的座位安排。

### 2. 匯入學生名單
可擇一方式建立名單（支援後續編輯）：
- **貼上文字**：貼上 CSV 內容後匯入。
- **匯入檔案**：上傳 `.csv` / `.xlsx` / `.xls`。
- **手動新增**：逐筆輸入學生資料。

建議欄位（可下載範例 CSV/Excel）：
`學號,中文名,性別,前後需求,組別,備註,固定座位,限制標記`

- **性別**：男 / 女 / 其他 / 不填
- **前後需求**：前排 / 後排 / 不指定（預設）
- **固定座位**：例如 `R1C2`（第 1 列第 2 行，依實際座位編號）
- **限制標記**：相同代碼的學生需分開；驚嘆號越多代表需分得越遠，例如 `A!`、`A!!`、`A!!!`

### 3. 設定排位規則
- **基底排列模式**：隨機、依學號遞增/遞減、依姓名遞增/遞減。
- **填入方向**：橫排／直排／S 型等多種順序。
- **前後排排數**：指定前排與後排範圍以滿足前後需求。
- **選項**：男女盡量間隔、分組平均分散且避免同組相鄰。
- **分開規則**：可於「管理分開規則」手動設定需分開的學生。
- **優先順序（概略）**：鎖定/固定 > 不可排位區塊 > 特殊需求（前後、分開、分組）> 男女間隔 > 基底排列（部分規則為盡力滿足的啟發式結果）。

### 4. 編排與微調
- 點選側邊欄 **「🎲 抽號編排座位」** 進行編排（含抽號動畫）。
- **拖曳**座位可交換學生；**右鍵**座位可進行鎖定、禁用、指派學生等操作。
- 支援**復原／重做**與**儲存目前版本**至編排歷史，方便比較與還原。

### 5. 檢視、匯入匯出與列印
- **檢視**：調整座位圖「字級」、使用「放大座位圖」或「全螢幕」以利課堂顯示。
- **匯出/匯入**：JSON（完整狀態/配置）、名單 CSV。
- **輸出**：PNG 圖檔、列印或另存 PDF（透過瀏覽器列印功能）。
- **自動儲存**：變更會自動保存於本機瀏覽器 `localStorage`（清除瀏覽資料可能移除）。

## 本機使用與部署

### 本機開啟
1. 下載或 clone 本專案。
2. 直接以瀏覽器開啟 `index.html` 即可使用。

> 建議使用現代瀏覽器。Excel 匯入與 PNG 匯出、字體載入需可連線至 CDN（見下方說明）。

### 部署到 GitHub Pages
1. 將 `index.html`、`styles.css`、`app.js`（及所需資源）推送至 GitHub 儲存庫。
2. 在 GitHub Repo 設定 **Settings → Pages**，選擇部署來源（如 `main` 分支 / root）。
3. 等待部署完成後，即可透過 Pages 網址存取。

## 技術說明
- 純靜態前端：`HTML` / `CSS` / `JavaScript`，無後端、無資料庫。
- 瀏覽器儲存：使用 `localStorage` 保存工作狀態。
- 外部 CDN（需網路）：SheetJS（`xlsx`，Excel 匯入/範例）、`html2canvas`（PNG 匯出）、Google Fonts（字體）。離線或受限網路環境下，相關功能可能受影響。

## 專案結構
- `index.html`：頁面結構與介面
- `styles.css`：樣式與主題
- `app.js`：狀態管理、排位邏輯、匯入匯出與互動
- `.agents/skills/frontend-design/`：設計輔助 skill 資料（可選）

## 隱私與資料
- 所有名單與排位資料僅儲存在使用者本機瀏覽器，不會上傳至伺服器。
- 匯出的檔案（JSON/CSV/PNG/PDF）由使用者自行保存與分享。
